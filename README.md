# vr-aquatherapy
chonky boi

VR (Meta Quest) app with a main menu and two calm walking environments:
**Forest** (collect mushrooms) and **Beach** (collect seashells).
Look at a collectible for 1.5 s, or point at it and press the trigger / pinch, to collect it.
The controller **Menu** button returns to the main menu.

See [Required Tags and Layers](doc/TAGS_AND_LAYERS.md) for the Unity tag and layer
assignments needed when creating prefabs and environments.

See [Parameters and Configuration](doc/PARAMETERS_AND_CONFIGURATIONS.md) for the parameters and configuration options available in the project.
